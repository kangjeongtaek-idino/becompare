# 수동 확인용 스크립트

초기 개발 때 기능을 손으로 확인하려고 쓴 스크립트입니다. 자동 검사가 아니며 CI에서 실행하지 않습니다.
자동 회귀 검사는 `python tools/test_regressions.py` 하나입니다.

- `ui.ps1`: 실제 창을 띄워 컨트롤 ID로 클릭·입력을 보내고 화면을 캡처하는 도우미. `t_*.ps1`이 불러 씁니다.
- `t_*.ps1`: 기능별 시나리오. 대부분 결과를 화면 캡처나 출력으로 보여 줄 뿐, 통과·실패를 판정하지 않습니다.
- `shot.ps1`, `tree.ps1`: 창 캡처, 컨트롤 트리 출력.
- `clean_ini.ps1`: 설정 파일의 시험용 항목 정리.
- `mk_docs.py`, `mk_media.py`, `mk_xlsx.py`: 시험용 문서·미디어·XLSX 파일 생성기.
- `mini_ftpd.py`: FTP 폴더 비교를 시험하는 작은 FTP 서버.

주의할 점:

- 저장소 위치는 스크립트 위치 기준(`$PSScriptRoot\..\..`)으로, 임시 폴더는 `$env:TEMP`로 바꿔 두었습니다.
  경로만 바꿨고 그 뒤로 다시 실행해 보지는 않았습니다.
- 일부 시나리오는 화면 좌표로 마우스를 움직이므로 창 크기·배율이 다르면 맞지 않습니다.
- 실제 창을 띄우고 `%TEMP%` 아래에 시험 폴더를 만들었다 지웁니다. 실행하기 전에 내용을 읽어 보세요.
