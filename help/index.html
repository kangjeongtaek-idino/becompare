처음 사용하기

  1. 홈 화면의 카드나 파일 메뉴에서 비교할 종류를 고릅니다. 소스 코드는 텍스트 비교, 두 폴더는 폴더 비교, CSV·엑셀 데이터는 표 비교가 적합합니다.
  2. 왼쪽·오른쪽 경로 칸에 파일 또는 폴더를 지정합니다. 찾아보기 버튼을 사용하거나 경로를 직접 입력할 수 있습니다.
  3. 비교 또는 F5를 누릅니다. 색과 차이 이동 버튼으로 바뀐 부분을 확인합니다.
  4. 반영할 방향을 확인한 뒤 가져오기·복사·저장을 실행합니다. 텍스트를 편집했다면 Ctrl+S로 저장합니다.

예: C:\작업\이전을 왼쪽, C:\작업\현재를 오른쪽에 지정하면 추가·삭제·변경 파일을 볼 수 있습니다. 화살표는 변경을 반영할 방향입니다. 실행 전에 원본과 대상 경로를 확인하세요.

세션은 탭으로 열립니다. 탭 줄의 ×는 현재 탭을 닫고, 톱니바퀴는 환경설정, 빨간 종료 아이콘은 프로그램을 종료합니다. 홈 탭은 닫히지 않습니다.

홈 · 파일 찾기

  1. 파일 이름 일부를 검색 칸에 입력합니다. 처음에는 색인을 만드는 데 시간이 걸릴 수 있으며, 읽은 범위부터 검색됩니다.
  2. 드라이브·종류·클라우드·확장자·폴더 필터로 결과를 좁힙니다. 확장자는 pdf;docx처럼 여러 개를 적습니다. 폴더 옆 … 버튼으로 위치를 고를 수 있습니다.
  3. 열 머리글을 누르면 이름·날짜·유형·크기·폴더 순으로 정렬합니다. 같은 머리글을 다시 누르면 방향이 바뀝니다.
  4. 더블클릭하면 연결된 프로그램으로 엽니다. 우클릭하면 프로그램 선택, 폴더에서 보기, BeCompare에서 열기, 경로 복사 등을 사용할 수 있습니다.

Ctrl·Shift를 사용해 여러 항목을 선택할 수 있습니다. 전체 선택을 누르면 선택 색으로 표시되고 버튼은 전체 해제로 바뀝니다. 다시 누르면 선택이 해제됩니다. 삭제는 확인 창의 대상·개수를 확인한 뒤 확정하며, 삭제된 항목은 결과에서 사라집니다.

검색어 옆 ×는 검색어를 지우고, 필터 초기화는 필터만 초기화합니다. 이름 일부 검색이며 파일 내용·정규식 검색은 지원하지 않습니다. 색인 뒤 외부에서 새로 만든 파일은 앱을 다시 실행해야 반영됩니다.

최근 세션은 홈에서 다시 열 수 있습니다. 최근 목록에서 제거하는 것은 원본 파일 삭제가 아닙니다.

폴더 비교 · 동기화

  1. 양쪽 폴더를 지정하고 비교합니다. 목록은 왼쪽 이름·크기·날짜, 가운데 동작, 오른쪽 날짜·크기·이름으로 읽습니다.
  2. 상태 버튼으로 같은 항목·다른 항목·한쪽에만 있는 항목을 골라 봅니다. 이름 필터로 범위를 좁힙니다.
  3. 비교 기준을 선택합니다. 빠른 점검은 크기·수정 시각, 실제 바이트 확인은 내용 또는 CRC32 비교를 사용합니다. 같은 크기·시각만으로 내용까지 같다고 단정할 수는 없습니다.
  4. 파일을 더블클릭하면 형식에 맞는 비교로 엽니다. 목록 아래 미리보기에서도 차이와 이전·다음 파일을 살펴볼 수 있습니다.
  5. 선택한 항목에 복사 →/←, 이동, 삭제, 시각 맞춤, F2 이름 바꾸기 등을 적용합니다.

톱니바퀴로 옵션 줄을 펼치면 이름 제외, 크기·최근 수정 기간, 속성 등의 조건을 설정할 수 있습니다. 제외 패턴은 *.log;node_modules처럼 적습니다.

방식사용 목적
갱신왼쪽의 변경을 오른쪽에 반영합니다.
미러오른쪽을 왼쪽과 맞춥니다. 오른쪽에만 있는 항목이 삭제 대상이 될 수 있습니다.
양방향양쪽의 상태에 따라 계획된 방향으로 반영합니다.
표시된 동작대로가운데 열에 지정한 →·←·건너뜀대로 반영합니다. 가운데 칸 클릭이나 Space로 바꿉니다.

동기화는 계획 검토 창에서 대상과 방향을 확인한 다음 실행하세요. 특히 미러의 삭제 대상을 확인하세요. 스캔에 접근 오류가 있으면 동기화를 진행할 수 없습니다.

되돌리기·다시 실행으로 파일 작업 단계를 되돌릴 수 있습니다. 외부에서 파일이 변경됐다면 보호를 위해 중단할 수 있습니다. 보고서 · 내보내기에서 HTML·XLSX·DOCX를 저장합니다.

ZIP·스냅샷·FTP는 읽기 전용 입력으로 사용할 수 있습니다. 스냅샷(.bcss)은 파일 목록·크기·시각·CRC를 기록하며 원본 내용은 담지 않습니다. ZIP은 암호화·ZIP64를 지원하지 않으며 전체 512MiB, 개별 압축 해제 256MiB 한도가 있습니다. SFTP·FTPS는 지원하지 않습니다.

텍스트 비교

  1. 두 파일을 열고 F5로 비교합니다. 파란색은 수정, 초록색은 추가, 회색은 삭제 구간을 나타냅니다. 줄 안의 진한 영역은 바뀐 단어나 문자입니다.
  2. 이전·다음 차이 버튼 또는 F7/F8로 이동합니다. Shift를 함께 누르면 이전 차이로 갑니다.
  3. 필요한 블록만 →/← 가져오기로 반영하거나 편집 가능한 창에서 직접 수정합니다.
  4. 수정 후 F5로 표시를 다시 맞추고 Ctrl+S로 저장합니다.

공백·대소문자·주석 무시는 의미 있는 변경만 찾을 때 사용합니다. 단어 강조 / 문자 강조는 줄 안 차이를 살피는 옵션입니다. 스크롤 동기화는 두 창을 함께 이동합니다. 줄 번호는 거터의 번호를 표시합니다.

변경 없는 구간 접기는 차이 주변 문맥 1·2·3·4·8줄만 남깁니다. ⋯를 누르면 해당 구간을 펼칩니다. 통합 보기는 변경을 한 흐름으로 읽는 데, 공백 표시는 공백·탭 확인에 사용합니다. 이 표시 상태에서는 직접 편집에 제한이 있으며, 편집·저장 작업에서 원래 보기를 복원할 수 있습니다.

분리된 변경 옵션으로 변경 구간의 표시 방식을 조정하고, 수동 정렬은 양쪽에서 대응하는 줄을 지정할 때 사용합니다. Ctrl+G는 지정한 줄로 이동합니다. 찾기·바꾸기로 문자열을 찾거나 수정하고, 북마크로 다시 볼 위치를 표시합니다.

패치 저장 / 패치 복사는 비교 결과를 unified diff로 내보냅니다. XLSX 내보내기는 비교 결과를 표로 저장합니다. 원본 수정은 Ctrl+S로 별도로 저장해야 합니다.

텍스트 편집

파일 → 새 텍스트 편집에서 파일 하나를 열어 수정합니다. 찾기·바꾸기, 구문 강조, 줄·열 표시를 사용하고 Ctrl+S로 저장합니다. 파일의 인코딩과 줄바꿈 형식을 보존합니다.

  • Enter: 앞줄의 들여쓰기를 이어받습니다. 괄호 뒤에서는 새 줄에 들여쓰기를 추가합니다.
  • Shift+Enter: 현재 줄 아래에 새 줄을 만듭니다. Ctrl+Alt+Enter: 위에 새 줄을 만듭니다. Ctrl+Enter: 캐럿 위치에서 줄을 나눕니다.
  • Home: 줄의 첫 글자와 줄 시작 사이로 이동하는 스마트 Home 동작을 제공합니다.
  • 괄호·따옴표 자동 입력: 가능한 문맥에서 닫는 짝을 함께 넣습니다. 환경설정에서 끌 수 있습니다.
  • Ctrl+Z / Ctrl+Y: 편집을 되돌리거나 다시 실행합니다.

이 편집 기능은 텍스트 비교의 편집 창과 병합 출력 창에서도 사용할 수 있습니다. 읽기 전용 입력 창에서는 동작하지 않습니다.

텍스트 병합

왼쪽·오른쪽은 합칠 두 버전, 기준(Base)은 두 버전이 갈라지기 전 공통 파일, 출력은 결과를 저장할 파일입니다.

  1. 입력 두 개와 가능하면 기준 파일을 지정합니다. 원본과 구분되는 출력 경로를 고르면 결과를 검토하기 쉽습니다.
  2. 병합을 실행하고 충돌 이동 버튼으로 미해결 부분을 살펴봅니다.
  3. 충돌마다 왼쪽 / 오른쪽 / 둘 다 채택을 선택하거나 출력 창을 직접 고칩니다.
  4. 3-way에서 단순 충돌 해결을 실행하면 같은 줄의 서로 겹치지 않는 변경을 자동으로 합칠 수 있습니다. 해결되지 않은 충돌은 직접 검토합니다.
  5. 출력 전체와 남은 충돌 표식을 확인한 다음 Ctrl+S로 저장합니다.

전체 채택은 많은 구간을 한 번에 바꾸므로 결과를 검토하세요. 채택 동작은 되돌리기가 가능합니다. DOCX 내보내기는 검토용 문서이며 병합 출력 파일 저장과는 별도입니다.

폴더 병합 (3-way)

  1. 왼쪽·오른쪽·기준 폴더와 출력 폴더를 지정합니다.
  2. 비교하여 같음·한쪽 변경·추가·삭제·충돌 상태를 확인합니다.
  3. 항목별로 왼쪽·오른쪽·기준 채택 또는 삭제·제외 등 반영할 동작을 고릅니다.
  4. 충돌 파일은 3-way 텍스트 병합으로 열어 내용을 해결합니다.
  5. 출력 폴더로 병합을 실행하고 병합됨·미해결 충돌·복사 실패 요약을 확인합니다.

자동 판정만으로 충돌 파일의 내용이 모두 해결되지는 않습니다. 출력 폴더를 확인하고 남은 충돌은 개별적으로 처리하세요.

표 비교 (CSV · TSV · XLSX)

  1. 두 표 파일을 지정합니다. XLSX의 특정 시트는 매출.xlsx#요약 또는 매출.xlsx#2처럼 이름·번호로 고릅니다. 번호는 1부터 시작합니다.
  2. 행이 같은 순서라면 행 번호로, 순서가 다르다면 공통 식별자 열을 키로 비교합니다. 복합 키는 2,3처럼 지정합니다.
  3. 숫자·날짜 허용 오차와 무시할 열을 필요에 맞게 정합니다.
  4. 비교를 실행하고 차이만 보기로 변경 셀을 검토합니다. XLSX로 결과를 내보낼 수 있습니다.

예: 직원 목록의 정렬 순서가 바뀌었다면 사번 열을 키로 지정하세요. 행 번호만 비교하면 같은 사람의 정보가 서로 어긋나 보일 수 있습니다.

시트 이름으로 찾지 못하면 #번호를 사용하세요. 시트를 지정하지 않으면 기본 워크시트 파트를 읽습니다.

헥스 비교

두 바이너리 파일을 열면 오프셋(파일 내 위치), 바이트의 16진수 값과 차이를 확인할 수 있습니다. 차이만 보기와 이전·다음 차이로 바뀐 위치를 찾습니다.

  1. 찾기에서 바이트 패턴을 찾아 이동합니다.
  2. 편집할 바이트를 선택하여 16진수로 수정하거나 같은 길이의 바이트 패턴으로 바꾸기·모두 바꾸기를 합니다.
  3. 수정한 파일과 위치를 확인하고 Ctrl+S로 저장합니다.

바이너리 수정은 파일 형식을 깨뜨릴 수 있으므로 의미를 아는 바이트만 변경하세요. 두 파일 전체를 메모리에 올리므로 큰 파일은 메모리가 많이 필요합니다.

이미지 비교

  1. 왼쪽·오른쪽 이미지를 엽니다.
  2. 나란히로 전체 모습을 보고, 차이 지도로 다른 픽셀을 찾거나 겹치기로 위치 어긋남을 확인합니다.
  3. 확대·축소, 회전·뒤집기로 방향과 위치를 살펴봅니다. RGB 허용 오차를 조정하면 작은 색 차이를 무시할 수 있습니다.

예를 들어 화면 캡처 두 장의 배치 변경은 겹치기로, 미세한 색 변화는 차이 지도로 확인합니다. DOCX 내보내기로 검토 결과를 보관할 수 있습니다.

버전 · 레지스트리 · 미디어 비교

버전 비교

두 EXE·DLL 등을 지정하고 비교합니다. 파일 크기·수정 시각, 고정 버전, 설명·회사명 같은 리소스 문자열을 확인합니다. 버전 리소스가 없는 파일은 해당 정보가 비어 있을 수 있습니다. 실제 내용 비교가 필요하면 헥스 비교를 사용하세요.

레지스트리 비교

HKCU\Software\제품A처럼 두 키 경로를 지정합니다. 비교하면 하위 키와 문자열·숫자·이진 값의 차이가 표시됩니다. 읽기·비교용이며 값을 직접 수정하는 도구가 아닙니다. 큰 키는 비교 시간이 길어질 수 있습니다.

미디어 비교

MP3·FLAC 두 개를 열어 제목·아티스트 등 태그, 오디오 정보, 표지 유무를 비교합니다. 태그를 제외한 오디오 데이터 CRC32도 확인하므로 태그만 다른 경우를 구분하는 데 유용합니다. 태그를 편집하거나 오디오를 재생·변환하는 기능은 아닙니다.

이 세 종류의 결과는 DOCX 검토 문서로 내보낼 수 있습니다.

문제 해결 · 안전한 저장

다른 창에서 바뀐 파일이라 저장되지 않아요

열었을 때와 디스크 내용이 달라지면 덮어쓰기를 중단하고 편집 내용을 유지합니다. 변경 내용을 다른 이름으로 저장한 뒤 최신 파일을 다시 열어 비교하세요. 여러 앱 인스턴스를 실행할 수 있지만 동일한 파일을 동시에 수정할 때는 이 보호가 동작합니다.

편집하려는데 입력되지 않아요

접기·통합 보기·공백 표시를 해제하고 편집 가능한 창인지 확인하세요. ZIP·스냅샷·FTP 입력과 병합의 원본 창은 읽기 전용입니다.

비교 색이 편집 내용과 맞지 않아요

텍스트를 직접 편집한 뒤 F5를 눌러 정렬과 차이 표시를 다시 계산하세요.

파일을 읽거나 저장하지 못해요

경로·권한·읽기 전용 속성·다른 프로그램의 잠금·남은 디스크 공간을 확인하세요. ZIP은 손상된 구조·체크섬 불일치·안전하지 않은 내부 경로·지원하지 않는 압축 방식이면 거부합니다.

검색에서 새 파일이 보이지 않아요

이름 검색과 필터를 먼저 확인하고, 색인 이후 외부에서 생성한 파일은 앱을 재시작해 다시 검색하세요.

도움말을 다른 PC에서도 사용하려면?

bcgui.exe와 같은 위치에 help 폴더를 함께 복사하세요. help/index.html을 직접 열어도 됩니다. 이 문서는 외부 스크립트·폰트·네트워크 연결을 사용하지 않습니다.
